# Core Principles

- **Clear over clever**: Write code that is obvious and easy to understand.
- **Zero value**: Types have default zero values; avoid nil checks when zero value is sensible.
- **Return early**: Exit functions as soon as possible; avoid deep nesting.
- **Happy path**: Structure code for the normal case, handle errors secondarily.
- **Explicit is better than implicit**: Favor explicit error handling over magical defaults.
- **Small is better than large**: Keep functions and types focused and compact.
- **Composition over inheritance**: Combine types and behaviors through embedding and composition.
